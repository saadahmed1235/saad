# Digital Agent Pro - Portfolio & AI Agency Website

> Sovereign Intelligence & Digital Engineering — High-velocity digital services, full-stack web engineering, and autonomous AI agent orchestration.

## 🚀 Overview

A responsive, high-performance portfolio and agency website designed with the **Obsidian Cyber Luxe** design system.

- **Obsidian Dark Aesthetic:** Pure `#090A0F` base canvas with Electric Violet (`#8B5CF6`) and Cyber Cyan (`#06B6D4`) luminous accents.
- **Interactive AI Assistant:** Floating chatbot drawer with simulated conversational intelligence, fast turnaround times, and pricing guidance.
- **Client Operations Hub:** Interactive dashboard telemetry, dynamic SVG 30D/90D velocity toggle, live deliverables checklist, and downloadable executive intelligence reports.
- **Strategy Call Booking Engine:** Built-in modal for booking 30-minute discovery sessions.
- **Comprehensive Services Matrix:** Dynamic category filters for YouTube SEO, Meta Ads, Web Development, and Autonomous AI.
- **Case Studies Showcase:** High-impact case study cards with detailed solution modal overlays.
- **Fully Responsive:** Custom mobile navigation drawer and optimized typography across all device breakpoints.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript** (Zero build step required)
- **Tailwind CSS (CDN)** with custom Obsidian Cyber Luxe theme tokens
- **Typography:** Plus Jakarta Sans (Headings) & Inter (Body & Data)
- **Icons:** Google Material Symbols Outlined

---

## 💻 Running Locally

Simply serve the directory with any local static web server or open `index.html` directly in your browser:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Using PHP
php -S localhost:8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
